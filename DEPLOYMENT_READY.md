### For Yegara cPanel Hosting

**Backend Deployment:**
```bash
1. Create directory: public_html/api
2. Upload backend files
3. Create Node.js app in cPanel
4. Set environment variables
```

```bash
1. Build: npm run build

3. Configure domain
```

**Backend .env:**
```

DB_USER=root
DB_PASSWORD=password
DB_NAME=smarthms
JWT_SECRET=your_secret_key
NODE_ENV=production
PORT=5000
```
