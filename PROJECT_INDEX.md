## 🎓 HOW TO USE

### Quick Start (5 minutes)

1. **Start Backend**

   ```bash
   cd backend
   npm install
   npm start
   ```

2. **Start Frontend**

   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Open Browser**

   ```
   http://localhost:5173
   ```

4. **Login**
   ```
   Email: admin@smarthms.com
   Password: admin123
   ```

### Seed Demo Data

```bash
cd backend
npm run seed:demo
```

### Run Tests

```bash
# Backend
npm test

# Frontend
npm run test
```
