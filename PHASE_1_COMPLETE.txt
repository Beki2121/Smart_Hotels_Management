🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

1. Install Backend
   $ cd backend
   $ npm install

2. Install Frontend
   $ cd ../frontend
   $ npm install

3. Create Database
   $ mysql -u root -e "CREATE DATABASE smarthms CHARACTER SET utf8mb4;"

4. Configure
   $ cd backend
   $ # Edit .env with your MySQL credentials

5. Run Migrations
   $ npm run migrate

6. Start Backend
   $ npm run dev  # Terminal 1 - runs on port 5000

7. Start Frontend
   $ cd ../frontend
   $ npm start    # Terminal 2 - runs on port 3000

8. Test API
   $ curl http://localhost:5000/api/v1/health
